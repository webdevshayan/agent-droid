Command reference

CommandEffect
agentdroid devicesList attached devices — clear error when none (adb runtime).
agentdroid launch <path.apk>adb: validate then install the APK · fake: start the simulated app.
agentdroid closeadb: send HOME (app stays installed) · fake: end the session.
agentdroid install <path.apk>Alias of launch for the adb runtime.
agentdroid snapshotDump the screen; one line per tappable element with its ref.
agentdroid snapshot --xmlPrint the raw uiautomator XML instead.
agentdroid tap @eNTap the element's center.
agentdroid type <text>Type into the focused element (tap a field first).
agentdroid swipe @eA @eBSwipe from element A to element B.
agentdroid swipe x1 y1 x2 y2Swipe between raw coordinates.
agentdroid screenshot [--out <path>]Capture a PNG — without --out it goes to stdout, so agentdroid screenshot > screen.png works.
agentdroid clear @eNFocus the element, move-end, bounded DEL sweep (40 chars).
agentdroid back / homeSystem navigation keys.
agentdroid --serial <id> <cmd>Target a specific device (short form -s).
agentdroid --runtime fake|adb <cmd>Pick the runtime: simulated app (no device) or adb.
agentdroid help · --versionUsage text · build version.

Exit codes

CodeMeaningAgent action
0SuccessContinue the loop.
1Runtime error (no device, adb missing, APK not found, ref out of range)Retry sensible alternatives; read stderr.
2Usage error (unknown command, malformed ref, oversized text)Fix the command — do not retry blindly.

Snapshot line format

@eN  <class>  [text="…"]  [desc="…"]  [id=<resource-id>]  [pkg=<package>]
    [clickable]  [scrollable]  [disabled]  bounds=[x1,y1][x2,y2]  center=(x,y)

Empty fields are omitted; text/desc are Go-quoted so one element is always exactly one line.

Typing rules

type enforces an allowlist — [a-zA-Z0-9-_.:,!?@#~^%*+=/], spaces become %s — and rejects shell metacharacters, control characters and non-ASCII with exit 1, instead of risking injection into the device shell. Hard cap: 4096 bytes, enforced before any copy or process spawn.
