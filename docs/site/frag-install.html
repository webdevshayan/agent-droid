Install

Requires Go 1.22+ and Android platform-tools (adb) on PATH. AgentDroid talks to devices through adb; adb itself is installed separately.

Install the CLI

go install github.com/webdevshayan/agent-droid/core/cmd/agentdroid@latest

Two runtimes

--runtime fake needs nothing at all — it is a simulated app built into the binary, ideal for CI and for trying the agent loop. --runtime adb (default) drives real devices and emulators: download Android platform-tools from developer.android.com, put them on your PATH; Wi-Fi devices need adb connect <host> first. Other runtimes plug in via the driver protocol.

Verify

$ agentdroid --version
agentdroid 0.1.0

$ agentdroid devices
List of devices attached
EMU1234	device product:sdk_gphone64_x86_64 model:sdk_gphone64_x86_64

Target a specific device

With several devices attached, pick one globally: agentdroid --serial EMU1234 snapshot (short form -s).

Build from source

git clone https://github.com/webdevshayan/agent-droid
cd agent-droid
go build -o agentdroid ./core/cmd/agentdroid
go test ./tests
