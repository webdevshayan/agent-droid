AI mobile testing CLI

Give your agent hands on Android.

AgentDroid reads any screen as text refs — @e1, @e2, @e3 — so an AI agent can snapshot, tap @e3, type and verify in plain text. No screenshots, no vision models, no pixel guessing — and with --runtime fake it runs against a simulated app with no device at all.

 the agent loop
$ agentdroid --runtime fake launch demo.apk
launched demo.apk
$ agentdroid --runtime fake snapshot
@e3  android.widget.Button  text="Sign in"  clickable  bounds=[340,400][740,520]  center=(540,460)
# the agent decides: tap the button
$ agentdroid --runtime fake tap @e3
tapped @e3 at (540,460)
$ agentdroid --runtime fake snapshot
@e1  android.widget.TextView  text="Welcome, demo@gmail.com"  …

Install

Requires Go 1.22+ and Android platform-tools (adb) on PATH.

go install github.com/webdevshayan/agent-droid/core/cmd/agentdroid@latest
adb version        &#8592; runtime dependency, installed separately
agentdroid --version

The binary is static and the module has zero third-party packages — nothing extra to audit. Or build from source: git clone https://github.com/webdevshayan/agent-droid && go build -o agentdroid ./core/cmd/agentdroid

Text over vision

One stable line per element with its ref, text and bounds. Fits any model's context — even a cheap one.

Agent-agnostic

Works with Z.ai, Claude Code, Cursor, Codex CLI or your own harness. If it can run a shell command, it can drive a phone.

Deterministic taps

Refs resolve to parsed element centers. No coordinate guessing, no re-shooting screenshots after rotation.

Hardened by default

Fuzzed parsers, 20 MiB dump cap, 500 MB payloads rejected in ~90 ms, strict charset allowlist for typing.

Script-friendly

Exit codes 0/1/2, grep-able output, snapshot --xml raw mode. Agents branch on the exit code, not on vibes.

Zero dependencies

One static Go binary over adb. No runtimes, no containers, no third-party supply chain.
